# Lone Star Valet: Region 3

Templates and how-tos for valet operations. **No codes, names, or phone numbers here** (public repo).

- `scheduling/`: shift-reminder message templates, weekly checklist
- `reports/`: report layouts (Open Lead Shifts)
- `sops/`: step-by-step procedures

## Weekly rhythm
| When | Task |
|---|---|
| Sunday ~noon | Build Open Lead Shifts report for the coming week; text Monday's crew |
| Monday ~noon | Text Tuesday's crew + rest of week; mark Confirmed in When2Work |
| As needed | Update the location codes sheet in Drive when a podium code changes |

## Open Lead Shifts report layout
| # | Location | Day / Date | Time | Best options (2–3) |
|---|---|---|---|---|

Rule: suggest people who have worked that location before. Flag shifts with nobody available.
